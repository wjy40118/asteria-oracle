SYNASTRY / DEMO
Final project / Design spec

A small, complete design proposition.

This interface is an interactive prototype. The design is evaluated on product definition, flow and tradeoffs, not the factual truth of divination.

Reframe “fortune telling” as a bounded, reviewable act of self-organization.

Asteria is designed for young adults moving through uncertainty. It places tarot, birth charts and relationship synastry inside one exploratory interface, using fisheye magnification to approach a clue and AI to translate symbols into actionable reflection.

01 / IDEA

Product statement

Enter one real question, choose tarot, a birth chart or a two-person synastry, and receive a reflective reading you can revisit. The target audience is people aged 18–35 facing uncertainty in relationships, work or identity.

02 / EXAMPLE

Concrete input and output

Enter “Should I change jobs?” and draw The Hermit · Upright. The output identifies information overload, suggests a seven-day low-noise review and gives one answerable reflection question.

03 / SCREEN

Main screen

Set intention on the left, explore the fisheye spread or chart in the center, and read the explanation on the right. Elements enlarge on approach and lock into focus on click.

04 / FLOW

User flow

Open→Choose ritual→Enter question→Draw/Generate→Explore→Keep

Edge cases: block generation when dates are empty; label Rising signs as estimates when birth time is missing; fall back to local card meanings when the model is unavailable.

05 / DATA

Data and licenses

The 22 Major Arcana names and interpretations ship with the project. No copyrighted card artwork is used. Birth coordinates stay in the browser and are not stored. Any future NASA/JPL data must be attributed.

06 / AI

Model and prompts

The preferred optional model is local open-source Qwen2.5-3B-Instruct. The prompt requires a reference to the user's question, a distinction between symbol and fact, an output of “Observation / Tension / Action / Reflection,” and no fixed predictions.

07 / SYSTEM

System structure

GitHub stores code and data; Streamlit Cloud runs the interface; browser JavaScript handles fisheye and animation; offline templates guarantee output without a model; Colab and Hugging Face are optional environments for local models.

08 / RISK

Risks and limits

Asteria does not predict death, illness, financial outcomes or another person's private thoughts. It does not replace therapy or medical care. Uncertain calculations are labeled, and every reading leaves room to disagree.

09 / COST

Zero-cost plan

Demo mode uses offline templates and Streamlit Community Cloud hosts the app for free. A self-hosted open-source model is optional, so no paid API is required.
