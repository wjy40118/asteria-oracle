Final project / Design spec

一个小而完整的设计命题。

界面是可交互原型。评分重点是产品定义、流程与取舍，不是占卜本身的真实性。

把“算命”重做成一次有边界、可回看的自我整理。

Asteria 面向不确定时期的年轻成年人。它把塔罗与出生星盘放在同一个探索界面里， 用鱼眼放大帮助用户靠近一条线索，再用 AI 将象征翻译成可执行的反思问题。

01 / IDEA

产品一句话

输入一个真实问题，选择塔罗或星盘，得到可回看的反思型解读。 目标用户是 18–35 岁、正在面对关系或职业不确定性的年轻人。

02 / EXAMPLE

具体输入与输出

输入“我该不该换工作？”并抽到 隐者 · 正位。输出会指出信息过载，建议先进行 7 天低干扰观察，并给出一个可回答的反思问题。

03 / SCREEN

主屏幕

左侧设定意图，中间是鱼眼牌阵或星盘，右侧解释随选择变化。靠近元素时放大，点击后固定细节。

04 / FLOW

用户流程

打开→选仪式→输入问题→洗牌/生成→探索→保存

边界情况：日期为空时阻止生成；出生时间缺失时显示“上升星座为区间估计”；无法生成解读时回退到本地牌义与反思问题。

05 / DATA

数据与许可

22 张大阿卡纳的名称与关键词随项目打包。不使用受版权保护的牌面图片。 出生坐标仅用于演示，不写入数据库；后续接入 NASA/JPL 可公开数据时需注明来源。

06 / AI

模型与提示词

首选本地开源 Qwen2.5-3B-Instruct。提示词要求：引用用户问题、区分象征与事实、输出“观察 / 张力 / 行动 / 反思”，禁止做确定性预测。

07 / SYSTEM

系统结构

GitHub 保存代码与资料；Streamlit Cloud 运行界面；浏览器 JavaScript 负责鱼眼与动画；离线模板保证无模型时仍有输出；Colab/Hugging Face 是可选的本地模型环境。

08 / RISK

风险与边界

不预测死亡、疾病、投资结果或他人隐私；不替代心理咨询与医疗。对不确定计算明确标注。所有解读保留“你可以不同意”的退出空间。

09 / COST

零付费方案

演示模式使用离线模板，Streamlit Community Cloud 免费托管。只有在用户主动启用时，才连接自托管的开源模型，因此不依赖付费 API。
